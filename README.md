# WebCraftStudio – Official Website & Blog

WebCraftStudio is a creative digital studio focused on building modern websites, strong visual identity, and powerful digital presence for businesses.
This repository contains the official website structure, blog system, visual assets, and legal documents used for the WebCraftStudio platform.

Our goal is to create professional, responsive, and visually impressive digital experiences that help brands grow online.

Project Overview

This project includes:

Main Website Page

Blog System with image articles

Visual assets and branding materials

Legal documents (Privacy Policy & Terms)

The website is designed with modern layout, responsive structure, animations, and clean UI suitable for creative agencies.
